📌 시나리오 1: 최초 기업 분석 전 해당 기업 폴더 만들기

새로운 관심 종목(예: 삼양식품 또는 테크윙)이 생겼을 때 가장 먼저 물리적 금고(폴더)를 세팅하는 단계입니다.

  1. 사용자 명령어 입력:
    text 삼양식품(003230) 기업 폴더 생성해줘
  2. 에이전트 자동 처리:
  3. e:\antigravity-work\my-skill\Stock_Research\삼양식품\ 경로에 아래 4개 하위 폴더와 기본 파일을 자동 생성합니다:
    • 1_Raw_Data/ : DART 사업보고서·분기보고서 PDF를 넣을 폴더
    • 2_Translated_DB/ : 파이썬 코드가 계산한 valuation_metrics.json과 auto_tables.md가 저장될 폴더
    • 3_Final_Reports/ : Phase1_Report.md/html, Phase2_Story.md/html, Phase3_DCF.md/html이 생성될 폴더
    • Weekly_Trend/ : 6열 규격 헤더가 세팅된 thesis_log.md, company_timeline.md, 개별 IR PDF 보관 폴더
  4. 사용자가 폴더 생성 직후 할 일:
  5. DART에서 다운로드한 최근 사업보고서 및 분기보고서 PDF를 1_Raw_Data/ 폴더에 넣습니다.
  6. (권장) my-stock 대시보드에서 해당 종목의 DART 재무 시계열(Data.xlsx 또는 cache.db)을 1회 불러와 둡니다.

📌 시나리오 2: 최초 기업 분석 보고서 작성 (신규 기업 첫 분석)

1_Raw_Data/에 보고서 PDF를 넣은 후 첫 분석을 실행하는 단계입니다. 종목 숙련도에 따라 2스텝 방식과 1턴 원샷 방식 중 편한 것을 골라 쓰시면 됩니다.

방법 A: 2스텝 검증 방식 (완전 초면인 신규 종목에 가장 추천)

BM 해부와 업종 분류(유형 A~D), 비영업자산 SOTP 규모를 먼저 눈으로 확인한 뒤 밸류에이션으로 넘어가는 가장 안전한 방식입니다.
- 1차 명령:
text 삼양식품(003230) Phase 1 분석해줘
(결과 확인: Step 1.5 SOTP 비영업자산 비중, Step 2.0 4대 레짐 변화, Step 3.5 리스크 도미노, Section 8 1순위 채택 지표 확인)
- 2차 명령 (수정이 필요 없으면 바로 입력):
text 삼양식품 Phase 2, 3 이어서 작성해줘

방법 B: 1턴 원샷 방식 (토큰 60% 절약 & 한 번에 전 과정 완성)

이미 비즈니스 모델을 잘 알고 있거나 한 번에 결과를 보고 싶을 때 사용합니다. SKILL.md의 요약 편향 차단 게이트 덕분에 한 번에 명령해도 Phase 1, 2, 3 어느 하나도 요약되지 않고 풀 버전으로 작성됩니다.
- 통합 명령:
text 삼양식품(003230) Phase 1~3 분석해줘

📌 시나리오 3: 추론 모델 변경 시 (기존 3.1 Pro / 3.8 Flash 작성 기업 ➔ 4.0 Argon 승격)

현재 보유하신 14~15개 기업처럼 과거 3.1 Pro나 3.8 Flash로 작성된 기업들을 4.0 Argon의 추론 깊이와 v4.2.2 규격으로 업그레이드할 때의 절차입니다.

  1. 절대 주의사항 (삭제 금지):
  2. 기존 기업 폴더를 통째로 삭제하시면 절대 안 됩니다. 1_Raw_Data/의 공시 파일과 Weekly_Trend/thesis_log.md에 누적된 과거 투자 가설 이력은 지우면 복구할 수 없는 핵심 자산입니다.
  3. 언제 실행하는가? (토큰 절약 운영 팁):
  4. 보유 종목 전체를 하루에 다 돌리실 필요가 없습니다.
  5. 평소 루틴대로 신규 분기실적 공시가 뜨거나, Global Trend가 나오거나, 매수/매도 타점을 다시 점검하고 싶은 종목부터 하나씩 순차적으로 실행하시면 됩니다.
  6. 사용자 액션 및 명령어:
  7. 안티그래비티 상단 모델 선택창에서 Gemini 4.0 Argon을 선택합니다.
  8. 평소와 똑같이 짧게 명령합니다:
    text 하나머티리얼즈 Phase 1~3 분석해줘
    (또는 단계별로 하나머티리얼즈 Phase 1 분석해줘 ➔ Phase 2, 3 진행해줘)
  9. 4.0 Argon 내부 자동 작동 (SKILL.md 제0원칙 3항 자동 발동):
  10. Argon이 하나머티리얼즈/3_Final_Reports/Phase1_Report.md를 열어보고 v4.2 필수 섹션(Step 1.5 SOTP, Step 2.0 4대 레짐 등)이 없는 3.8 구버전임을 스스로 감지합니다.
  11. 즉시 구버전 문맥 관성(Anchoring)을 차단하여 기존 3.8 보고서 본문을 무시하고, 1_Raw_Data/ 원문과 thesis_log.md 가설 이력만 읽어들인 뒤 백지상태에서 4.0 Argon의 깊은 인과 추론으로 Phase 1~3 전체를 새로 작성해 덮어씁니다.
  12. 기존 4열이었던 thesis_log.md 역시 과거 가설들을 하나도 잃어버리지 않고 [📊 직전 분기 QoQ 추이 + 🚨 반증 Kill-Switch 숫자]가 포함된 6열 표로 자동 승격시킵니다.

📌 시나리오 4: Global_Trend (2주 주기 산업·거시 딥리서치) 업데이트 시

  1. 내 사전 준비:
  2. Stock_Research/Global_Trend/ 아래에 날짜 폴더(예: 26.10.16~31/)를 만들고 신규 증권사 PDF 파일들을 넣습니다.
  3. 사용자 명령어 입력:
  4. 개별 종목에 반영할 때:
    text 리노공업 최신 Global Trend 반영해서 업데이트해줘
  5. 새 리포트에서 수혜주 스캔부터 하고 싶을 때:
    text Global_Trend/26.10.16~31 폴더의 신규 리포트들을 스캔해서 핵심 S-Curve 침투율 변화를 정리하고, 관련 보유종목(리노공업, 코미코) 업데이트해줘
  6. 4.0 Argon 내부 자동 작동:
